# Everything on one page

Every public object in gdc2maf with its full docstring, in pipeline order, so the
whole API can be read or searched in one place (`Ctrl-F` finds any name here).

It is generated from the same docstrings as the per-module pages in
{doc}`index` — nothing is written twice. Use {doc}`index` to find an object by
topic, this page to read them all, and the per-module pages for the canonical,
linkable entry for each one.

:::{note}
Cross-references elsewhere in this site point at the per-module pages, not at
this one, so that each object has exactly one address.
:::
